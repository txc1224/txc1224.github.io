<!-- KNOWLEDGE-IMPORT:START -->

## 三、数据库与数据建模

## TL;DR

> 会设计 schema、会写复杂查询、懂索引与事务。

## 阶段目标

- 能独立设计一个博客系统的完整 schema（用户、文章、评论、标签、点赞）并配上合理索引，能讲清每个索引为什么建。
- 能写出窗口函数（ROW_NUMBER / RANK / 分组累计）解决"每组取 Top N"这类真实业务问题。
- 能脱稿解释 B+ 树和 LSM 树的结构差异，以及为什么 MySQL InnoDB 用前者、很多 NoSQL/日志系统用后者。

## 推荐书单

### 📖 1. 《SQL 必知必会》

- **作者**: Ben Forta
- **链接**: https://book.douban.com/subject/26611900/
- **覆盖主题**: MySQL/PostgreSQL 基础语法、查询、联结、子查询、索引、事务
- **难度**: ⭐⭐
- **预计投入**: 2 周 / 每天 1.5h
- **状态**: unread
- **为什么读**: 最薄的 SQL 入门书，一页一个知识点，边读边敲就能建立完整语法地图；相比大部头教材，它是"先能干活"的最短路径。
- **阅读重点**: 第 1-15 章（查询、排序、过滤、分组、联结、子查询）精读并全部手敲；视图、存储过程、游标章节可泛读，用到再回来查。
- **配套笔记**: [[../../02-node-backend/sql-basics]]、[[../../02-node-backend/mysql-index]]
- **避坑**: 不要只看不敲——每一条 SELECT 都在本地 MySQL 里跑一遍；联结（JOIN）章节务必画图理解，这是后面所有复杂查询的地基。
- **我的收获**(留白): <读完后写，AI 写不出这段>

### 📖 2. 《MongoDB 实战》

- **作者**: Kristina Chodorow
- **链接**: https://book.douban.com/subject/27098038/
- **覆盖主题**: 文档建模、CRUD、聚合管道、索引、副本集与分片
- **难度**: ⭐⭐⭐
- **预计投入**: 3 周 / 每天 1.5h
- **状态**: unread
- **为什么读**: 作者是 MongoDB 核心贡献者，对"文档怎么建模"（内嵌 vs 引用）的取舍讲得最透——这正是从关系型思维切换到文档思维时最容易犯错的地方。
- **阅读重点**: 文档设计（内嵌/引用/反范式）、聚合管道（$group/$lookup/$facet）、索引与 explain 精读；分片与集群运维章节泛读，建立概念即可。
- **配套笔记**: [[../../02-node-backend/mongodb-modeling]]、[[../../02-node-backend/mongo-aggregation]]
- **避坑**: 别把 MongoDB 当"不用设计表结构的 MySQL"用——查询模式先行：先想清业务怎么查，再定文档结构，而不是反过来。
- **我的收获**(留白): <读完后写，AI 写不出这段>

### 📖 3. 《数据库系统概论》

- **作者**: Abraham Silberschatz
- **链接**: https://book.douban.com/subject/10548379/
- **覆盖主题**: 关系模型、范式、事务、ACID、并发控制与锁、查询优化、存储结构
- **难度**: ⭐⭐⭐⭐
- **预计投入**: 6 周 / 每天 1.5h
- **状态**: unread
- **为什么读**: 前两本教"怎么用"，这本教"为什么这样设计"——事务隔离级别、锁、B+ 树、查询优化器的原理，是面试和线上慢查询排查的底层弹药。
- **阅读重点**: 关系模型与范式（1NF-BCNF）、事务与 ACID、并发控制（锁/MVCC/隔离级别）、索引与存储（B+ 树）精读；分布式数据库、XML/对象数据库等章节可跳过。
- **配套笔记**: [[../../02-node-backend/transaction-isolation]]、[[../../02-node-backend/btree-vs-lsm]]
- **避坑**: 不要先读这本！先读完《SQL 必知必会》有了手感再回来啃理论，否则全是抽象概念没有落点；范式部分要结合真实反例（冗余导致更新异常）来理解，别背定义。
- **我的收获**(留白): <读完后写，AI 写不出这段>
