## 七、学习顺序与实操建议(总纲)

## TL;DR

> JS 全栈 4 个月自学路线: 语言 → 后端 → 数据 → 元框架 → 网络 → 工程化。边学边做完整项目,不要三线作战。

## 学习顺序总览

```
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ JS/TS    │ → │ Node.js  │ → │ 数据库   │ → │ Next.js  │ → │ 计算机网络│ → │ 工程化    │
│ 根基     │   │ 后端     │   │          │   │ 全栈     │   │ 基础     │   │ DevOps   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘   └──────────┘
   4 周           3 周           3 周           3 周           2 周(贯穿)     2 周
```

**关键原则**: 一个阶段没消化前,**不**进入下一阶段。比速度更重要的是**每阶段做出可演示的产出**。

## 边学边做的项目建议

> 不是看完书再做,而是**一边读一边做**。

- **技术栈**: `Next.js + Prisma/Sequelize + PostgreSQL`
- **推荐方向**(选一个就够):
  - 个人博客(评论 / 标签 / RSS)
  - 读书笔记(章节笔记 / 书单 / 摘录)
  - 待办协作工具(团队看板 / 评论 / 通知)
- **节奏**: 每读完一阶段,把对应功能"加进"这个项目
  - 阶段一: 把前端 UI 写完(交互 / 状态管理)
  - 阶段二: 把 API 跑通(登录 / CRUD)
  - 阶段三: 数据入库(关系模型 / 索引)
  - 阶段四: SSR / SSG 上线(静态页 + API 路由)
  - 阶段五: 反向代理 + HTTPS(Nginx + Let's Encrypt)
  - 阶段六: Docker 打包 + GitHub Actions 自动部署

## 避坑清单

1. **不要同时学 Java/Python**。先吃透 JS 全栈再扩展。你现在手里的 React/Vue 项目就是你最好的练兵场。
2. **不要一开始就读《数据库系统概论》**。先读完《SQL 必知必会》再回来啃理论。
3. **不要边看书边抄代码**。看完一章合上书自己写一遍,卡壳再回去看。
4. **不要在 04 阶段之前碰微服务、K8s**。先把单体 Next.js 部署跑通。
5. **不要跳过单元测试**。从阶段二开始,每个 API 写一个 happy path 测试。
