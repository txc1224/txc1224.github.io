# 正则表达式

> 正则是字符串处理的瑞士军刀，掌握语法 + 常用模式 + 断言即可覆盖 90% 场景。

---

## 语法速查表

| 语法               | 含义               | 示例               |
| ------------------ | ------------------ | ------------------ |
| `\d` / `\D`        | 数字 / 非数字      | `\d+` 匹配整数     |
| `\w` / `\W`        | 单词字符 / 非单词  | `\w+` 匹配标识符   |
| `\s` / `\S`        | 空白 / 非空白      | `\s+` 分割空格     |
| `^` / `$`          | 开头 / 结尾        | `^\d+$` 纯数字     |
| `.`                | 任意字符（除换行） | `/a.c/` 匹配 abc   |
| `*` / `+` / `?`    | 0+ / 1+ / 0或1     | `\d*` 零或多个数字 |
| `{n,m}`            | n 到 m 次          | `\d{6,8}`          |
| `[abc]` / `[^abc]` | 字符集 / 排除集    | `[a-z]` 小写字母   |
| `(...)`            | 捕获组             | `(\d{4})`          |
| `(?:...)`          | 非捕获组           | `(?:ab)+`          |
| `(?<name>...)`     | 命名捕获组         | `(?<year>\d{4})`   |

---

## 标志位

| 标志 | 含义                      | 示例                    |
| ---- | ------------------------- | ----------------------- |
| `g`  | 全局匹配                  | `/a/g` 匹配所有 a       |
| `i`  | 忽略大小写                | `/hello/i`              |
| `m`  | 多行模式（`^$` 匹配每行） | `/^start/m`             |
| `s`  | dotAll（`.` 匹配换行）    | `/a.b/s`                |
| `u`  | Unicode 模式              | `/\p{L}/u` 匹配任意字母 |
| `d`  | 匹配索引（ES2022）        | 返回 indices 属性       |

---

## 断言（零宽匹配）

```js
// 正向先行断言：匹配后面跟着指定模式的位置
'100px 200em'.match(/\d+(?=px)/g); // ['100']

// 负向先行断言：匹配后面不跟指定模式的位置
'100px 200em'.match(/\d+(?!px)/g); // ['20', '0']

// 正向后行断言：匹配前面是指定模式的位置
'$100 ¥200'.match(/(?<=\$)\d+/g); // ['100']

// 负向后行断言：匹配前面不是指定模式的位置
'$100 ¥200'.match(/(?<!\$)\d+/g); // ['200']
```

## 命名捕获组

```js
const dateReg = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const {
  groups: { year, month, day },
} = '2024-01-15'.match(dateReg);
// year: '2024', month: '01', day: '15'

// 替换中引用命名组
'2024-01-15'.replace(dateReg, '$<year>年$<month>月$<day>日');
// '2024年01月15日'
```

## 常用实战模式

```js
const patterns = {
  email: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
  mobile: /^1[3-9]\d{9}$/,
  url: /^https?:\/\/[\w-]+(\.[\w-]+)+([\w.,@?^=%&:/~+#-]*)?$/,
  idCard: /^\d{15}(\d{2}[\dX])?$/,
  chinese: /^[\u4e00-\u9fa5]+$/, // 纯中文
  password: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$/, // 至少含大小写+数字
  ipv4: /^(\d{1,3}\.){3}\d{1,3}$/,
};
```

## 字符串方法对比

| 方法                       | 作用     | 返回值              |    是否需要 `g` 标志    |
| -------------------------- | -------- | ------------------- | :---------------------: |
| `str.match(reg)`           | 匹配     | 匹配数组 / null     |   有 `g` 返回所有匹配   |
| `str.matchAll(reg)`        | 迭代匹配 | 迭代器（含捕获组）  |       必须有 `g`        |
| `str.search(reg)`          | 查找位置 | 首次匹配的索引 / -1 |         不需要          |
| `str.replace(reg, rep)`    | 替换     | 新字符串            |     有 `g` 替换所有     |
| `str.replaceAll(reg, rep)` | 全部替换 | 新字符串            |       必须有 `g`        |
| `str.split(reg)`           | 分割     | 数组                |         不需要          |
| `reg.test(str)`            | 测试匹配 | boolean             | 有 `g` 会改变 lastIndex |
| `reg.exec(str)`            | 逐次匹配 | 匹配对象 / null     |    有 `g` 可循环调用    |

## 高级技巧

```js
// replace 配合函数
'hello world'.replace(/\b\w/g, (c) => c.toUpperCase());
// 'Hello World'

// matchAll 迭代所有匹配（含捕获组）
const text = 'price: $10, tax: $2';
for (const m of text.matchAll(/\$(\d+)/g)) {
  console.log(m[1]); // '10', '2'
}

// 动态构建正则（注意转义）
const keyword = 'hello.world';
const escaped = keyword.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
const reg = new RegExp(escaped, 'gi');
```

## 常见陷阱

```js
// ❌ 全局正则的 lastIndex 状态问题
const reg = /\d+/g;
reg.test('abc123'); // true
reg.test('abc123'); // false（lastIndex 没重置）

// ✅ 每次使用新建正则，或手动重置
reg.lastIndex = 0;
reg.test('abc123'); // true
```

```js
// ❌ 贪婪匹配导致过度匹配
'<b>bold</b><i>italic</i>'.match(/<.*>/);
// '<b>bold</b><i>italic</i>'（匹配了整个字符串）

// ✅ 使用非贪婪匹配
'<b>bold</b><i>italic</i>'.match(/<.*?>/g);
// ['<b>', '</b>', '<i>', '</i>']
```

```js
// ❌ 忘记转义特殊字符
new RegExp('file.txt'); // . 会匹配任意字符

// ✅ 正确转义
new RegExp('file\\.txt');
```
