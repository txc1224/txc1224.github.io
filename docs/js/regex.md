# 正则表达式

## 速查表

| 语法            | 含义                  | 示例               |
| --------------- | --------------------- | ------------------ |
| `\d`            | 数字 [0-9]            | `\d+` 匹配整数     |
| `\w`            | 单词字符 [a-zA-Z0-9_] | `\w+` 匹配标识符   |
| `\s`            | 空白字符              | `\s+` 分割空格     |
| `^` / `$`       | 开头 / 结尾           | `^\d+$` 纯数字     |
| `.`             | 任意字符（除换行）    | `/a.c/` 匹配 abc   |
| `*` / `+` / `?` | 0+ / 1+ / 0或1        | `\d*` 零或多个数字 |
| `{n,m}`         | n 到 m 次             | `\d{6,8}`          |
| `(?:...)`       | 非捕获组              | `(?:ab)+`          |
| `(?<name>...)`  | 命名捕获组            | `(?<year>\d{4})`   |
| `(?=...)`       | 正向先行断言          | `\d+(?=px)`        |
| `(?!...)`       | 负向先行断言          | `\d+(?!px)`        |

```js
// 命名捕获组
const dateReg = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;
const {
  groups: { year, month, day },
} = '2024-01-15'.match(dateReg);

// 实用正则
const patterns = {
  email: /^[^\s@]+@[^\s@]+\.[^\s@]+$/,
  mobile: /^1[3-9]\d{9}$/,
  url: /^https?:\/\/[\w-]+(\.[\w-]+)+([\w.,@?^=%&:/~+#-]*[\w@?^=%&/~+#-])?$/,
  idCard: /^\d{15}(\d{2}[\dX])?$/,
  stripHtml: /<[^>]*>/g, // 去除 HTML 标签：str.replace(patterns.stripHtml, '')
};

// replace 配合函数
'hello world'.replace(/\b\w/g, (c) => c.toUpperCase()) / // 'Hello World'
  // 标志位
  pattern /
  gi; // g: 全局匹配，i: 不区分大小写，m: 多行，s: . 匹配换行，u: Unicode
```
